## Library Health

Mode: Operate. Audience: the server owner diagnosing library drift. Job: understand what is missing, moved, stale or untagged, then export a safe report. This route never repairs data.

THESIS: A diagnostic ledger, not a dashboard of decorative score cards. The summary is a ruled strip; the findings table is the page.

OWN-WORLD: Inherit The Printing Desk unchanged — paper, ink, signal blue for state, square 2px rules, Inter/Space Grotesk/JetBrains Mono, flat surfaces.

STORY: The owner scans, reads category counts, filters to a problem, inspects the exact admin-only path and copies the recommendation into the appropriate existing maintenance flow.

FIRST VIEWPORT: PageHeader with Scan and Export actions; a five-cell summary strip; category filter; semantic findings table. Empty and non-admin states replace the ledger.

FORM: Ruled diagnostic table within the existing Library workspace. seed: none (pinned) — “v4 kimliği ... dokunulmaz.”
